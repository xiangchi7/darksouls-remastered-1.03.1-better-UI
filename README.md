# Better User Interface — for Dark Souls: Remastered

## English

A texture pack that combines two Dark Souls: Remastered UI mods into one — with my own subjective edits made along the way:

- **Silver UI + Lock-on + Bow Aim + Translucent** (Nexus mod 39)
- **UI Icon Remake** (Nexus mod 667)

**What it does:** keeps Silver UI's silver menu skin and translucent panels and uses the UI Icon Remake's icons and menu art. Beyond simply stacking the two, several panels and menu elements were replaced and recomposed by hand, so this pack is not a straight copy of either original — 20 BC3 textures, no need to pick one pack over the other.

**Install:** requires DSR Texture Packer & Unpacker (DSR-TPUP). Close the game, point TPUP's **Texture Override** at this pack's `Texture Override` folder, click **Pack**. Restore with TPUP's **Restore**, or rename the `.tpupbak` files beside the archives back.

All art belongs to the authors of those two packs.
